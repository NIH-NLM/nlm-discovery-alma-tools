# OCLC to Alma

Workflows for bringing metadata from OCLC WorldCat into Alma.

## Tools

- [OCLC to Alma - Book](OCLC%20to%20Alma%20-%20Book/) - Searches OCLC by ISBN, evaluates candidate records, and imports the best record into Alma.
- [OCLC to Alma - Book batch](OCLC%20to%20Alma%20-%20Book%20batch/) - Standalone batch workflow that imports eBook records from an input spreadsheet and creates electronic portfolios in Alma.
- [OCLC to Alma - Journal](OCLC%20to%20Alma%20-%20Journal/) - Searches OCLC by ISSN, evaluates candidate records, and imports the best record into Alma.

## Instructional Video

[OCLC to Alma Book Program Demo](OCLC%20to%20Alma%20-%20Book/OCLC%20to%20Alma%20Book%20Program%20Demo.html) demonstrates the single-record book workflow. See the [Book README](OCLC%20to%20Alma%20-%20Book/README.md#instructional-video) for playback and download instructions.

You can download **both the HTML and MP4 files**, keep them in the same folder, and open the HTML file in a modern browser such as Chrome, Edge, Firefox, or Safari.

## Notes

- Keep Alma and OCLC keys in local key files and out of source control.
- Test in Alma Sandbox before running against Production.
